Plans de classe

Classes → salles → plans de classe • sauvegarde automatique locale

1. Salles

Une salle définit seulement une grille physique. Aucun élève n’est enregistré dans la salle.

2. Classes et élèves

Si la première ligne est « Élèves », elle est retirée automatiquement.

3. Plans de classe

Créer un plan de classe
Le plan copie la grille de la salle. Ensuite, les tables supprimées ou insérées appartiennent uniquement à ce plan.

4. Import / export

Le fichier contient toutes les salles, classes et tous les plans. Utilisez-le pour passer sur un autre poste.
● Sauvegarde automatique active

Aucun plan de classe

Cliquez sur une table ou un emplacement puis utilisez A pour marquer l’élève absent, Suppr pour retirer la table et I pour l’insérer. Les tables, rangées et colonnes se déplacent à la souris.
